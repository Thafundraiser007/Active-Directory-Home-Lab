# Active-Directory-Home-Lab
Active Directory home lab built in VMware showcasing AD DS installation, OU creation, user management, DNS, and domain joining.


# Active Directory Home Lab

## Overview
This lab demonstrates the deployment and administration of Active Directory Domain Services (AD DS) in a VMware environment.

## Skills Demonstrated
- Installing Active Directory Domain Services (AD DS)
- Promoting a server to a Domain Controller
- Creating Organizational Units (OUs)
- Creating and managing domain users
- Configuring DNS
- Joining a Windows client to the domain

## Environment
- VMware Workstation
- Windows Server
- Windows Client
- Active Directory Domain Services (AD DS)
- DNS
